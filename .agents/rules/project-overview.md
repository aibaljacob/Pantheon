# Pantheon

Pantheon is an AI-powered collaborative game production platform.

It is NOT a game publishing platform.

Primary objective:

Help game studios recruit talent,
manage projects,
track tasks,
manage assets,
and provide AI-powered insights.

The AI is NOT a team member.

The AI only provides:

- recommendations
- project health analysis
- profile extraction
- talent matching
- workflow insights

Never generate features outside this scope unless requested.
